`1 MiB = 1,048,576 bytes`。应用目录统计其中全部文件的逻辑大小，压缩包统计文件长度，均不包含独立的调试符号。下载包重新压缩或重新签名后，体积可能变化。iOS 包体测量不代表已完成真机安装验收。

Application directory sizes sum the logical sizes of their files. Archive sizes are file lengths. Separate debug symbols are excluded. Recompression or signing can change archive sizes. Measuring the iOS package does not imply it has been installed and tested on a device.

The Android APK passes `apksigner` v2 verification with identity `CN=RustSend, O=AimesSoft`. `aapt` confirms application ID `com.aimessoft.rustsend`, version name `1.0.0`, version code `10000`, ARM64, minimum SDK 26, target SDK 36, and compile SDK 37.

在仓库根目录可用 Python 读取应用目录和本地打包结果的大小：

```python
from pathlib import Path

for target in ("macos", "ios"):
    app = Path("target/bern") / target / "RustSend.app"
    size = sum(p.stat().st_size for p in app.rglob("*") if p.is_file())
    print(app, size, f"{size / 1048576:.2f} MiB")

for package in Path("dist").glob("RustSend-1.0.0-*"):
    if package.is_file():
        size = package.stat().st_size
        print(package, size, f"{size / 1048576:.2f} MiB")
```
