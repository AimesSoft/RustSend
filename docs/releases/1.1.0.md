# RustSend 1.1.0

RustSend 1.1.0 全面升级至 **Bern 0.3.2**（直接通过 crates.io 与官方 `bern` CLI 构建，不再随仓携带 `vendor/bern/` 快照），并移除接收页 Logo 对网页视图的依赖。

## 更新内容

- **升级至 Bern 0.3.2（移除仓库内快照）**：
  - 删除 `vendor/bern/` 源码快照，改用 crates.io 上公开发布的 `bern = "=0.3.2"` 与官方 `bern` 0.3.2 构建工具链。
  - 原先保留在本地快照中的平台能力（iOS `open_path` / `export_path`、`[app].local_network` 局域网权限声明、`bern package --target ios` 真机 `.ipa` 打包、Android 组播与文件服务、Windows 打包 `System32\tar.exe` / `curl.exe` 路径修复）已全部合入 Bern 上游。
- **彻底告别接收页 WebView**：
  - 接收页旋转 Logo 从 SVG 网页视图改为由系统合成器直接驱动的位图动画（Bern `spin` / `spin_period`），每 15 秒一圈，暂停接收时停在当前角度，开启“减少动态效果”时保持静止。
  - Linux 发行包不再依赖 WebKitGTK 6；Windows 不再为接收页 Logo 启动 WebView2。

## 安装说明

macOS 最低版本为 14，Android 为 8.0，iOS 为 17。Linux 推荐 Ubuntu 24.04+（GTK 4.14+、libadwaita 1.5+、libsoup 3，不再依赖 WebKitGTK 6），优先使用 `.deb` 安装依赖。Windows 在已安装 Windows App Runtime 2 时使用 WinUI 3，否则自动回退至系统 XAML。

macOS 应用采用临时签名、尚未公证；Windows 发行包未配置 Authenticode 签名；iOS 提供未签名的设备 IPA，需使用自有 Apple 开发者证书与描述文件签名后安装，局域网组播发现还需 Apple 批准的 `com.apple.developer.networking.multicast` 权限（未授权时可通过手动 IP 连接）。Android 安装只需 APK，`.dm` 为可选启动优化文件。

## English

RustSend 1.1.0 upgrades to **Bern 0.3.2** directly from crates.io and official `bern` CLI releases (dropping the vendored `vendor/bern/` snapshot) and removes the web view previously used for the spinning Receive logo.

### Highlights

- **Upgraded to Bern 0.3.2 (no vendored framework copy):**
  - Removed `vendor/bern/`; RustSend now depends directly on `bern = "=0.3.2"` from crates.io and builds with the official `bern` 0.3.2 CLI.
  - Platform capabilities previously maintained as local patches (iOS `open_path` / `export_path`, `[app].local_network` usage descriptions, native `bern package --target ios` `.ipa` packaging, Android multicast and document services, and Windows `System32\tar.exe` / `curl.exe` hardening) are now built directly into upstream Bern.
- **No WebView for the Receive logo:**
  - The spinning Receive page logo is now a bitmap turned by each platform's native compositor via Bern's `spin` / `spin_period` (15 seconds per turn, pauses at its current angle while receiving is paused, and stays still with reduced motion).
  - Linux packages no longer depend on WebKitGTK 6, and Windows no longer creates a WebView2 for the logo.

### Release assets

Assets follow `RustSend-1.1.0-OS-architecture` naming (`macOS-arm64.zip`, `Windows-x64-setup.exe`, `Windows-x64.zip`, `Linux-x64.deb`, `Linux-x64.tar.gz`, `Android-arm64.apk`, `Android-arm64.dm`, `iOS-arm64-unsigned.ipa`) together with `SHA256SUMS.txt`.
